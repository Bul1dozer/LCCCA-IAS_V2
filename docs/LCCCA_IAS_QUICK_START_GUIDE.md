# LCCCA-IAS Quick Start Guide

This guide is for first-time users who need to complete the most common tasks safely.

## 1. Log In

1. Open the LCCCA-IAS login page.
2. Enter your username and password.
3. Choose Sign In.
4. If two-factor authentication is enabled, enter the current code from your authenticator app.
5. After login, you should land on the Dashboard.

If login fails repeatedly, wait before trying again or request a password reset.

## 2. Add a Parent or Guardian

1. Open Parents.
2. Choose Add Parent.
3. Enter full name, email, phone, physical address, employer name, position, employer address, and employer phone where available.
4. Save the parent.
5. Open the parent profile to confirm the details.

## 3. Add a Learner

1. Open Learners.
2. Choose Add Learner.
3. Enter full name, grade, class, date of admission, status, and physical address.
4. Save the learner.
5. The system creates a unique learner number automatically.
6. Open the learner profile to confirm the details.

## 4. Link Parent and Learner

1. Open Parents.
2. Open the parent profile.
3. Choose Link Learner.
4. Select the learner.
5. Select the relationship type.
6. Save the link.
7. Confirm the learner appears under Linked Learners.

Repeat for each child linked to the same parent.

## 5. Assign Fees

1. Open Fee Catalogue.
2. Use the Catalogue tab to confirm the fee item exists and is active.
3. Open Learner Profiles.
4. Select the learner.
5. Review the assigned fees and monthly total.
6. Use Auto-Assign for matching mandatory fees, or Add Fee for optional learner-specific fees.

Only active monthly fee assignments are used by monthly invoice generation.

## 6. Generate a Parent Invoice

1. Open Invoices.
2. Choose Generate Invoice.
3. Set Invoice For to Parent (aggregate linked learners).
4. Select the parent.
5. Select the billing period.
6. Select the due date.
7. Choose Generate Invoice once.
8. Review the new invoice in the table.
9. Expand the row to confirm learner-specific line items.
10. Preview, download, or send the invoice.

The system creates one invoice number for the parent while keeping ledger charges linked to each learner.

## 7. Record a Payment

1. Open Payments.
2. Choose Capture Payment.
3. Select the correct learner by name and learner number.
4. Enter amount paid, date paid, payment method, reference number, and notes if needed.
5. Save the payment.
6. Open the receipt if required.

The system rejects zero or negative payment amounts and duplicate active payment references.

## 8. Change Your Password

1. Open Settings.
2. Find Change Password.
3. Enter your current password.
4. Enter and confirm the new password.
5. Save the change.

The new password must be at least 8 characters and must be different from the current password.

## 9. Enable Two-Factor Authentication

1. Open Settings.
2. Open the 2FA tab.
3. Choose Set Up 2FA.
4. Scan the QR code with an authenticator app.
5. Enter the current six-digit code.
6. Confirm setup.

Do not share the QR code or authenticator codes.

## 10. Log Out

When finished, choose Log Out from the sidebar, especially on a shared or office computer.

## Safe Billing Checklist

Before generating an invoice, confirm:

1. The parent is correct.
2. The linked learners are correct.
3. The learner grades are correct.
4. Fee profiles are correct and active.
5. The billing period is correct.
6. The due date is correct.
7. You clicked Generate Invoice only once.
